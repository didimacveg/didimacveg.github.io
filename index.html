Projects

gravity-lab

C++17 · validated

An N-body simulator of the Solar System, checked against astronomical measurement rather than eyeballed.

Problem
An orbit simulation always looks plausible. A poor integrator invents effects of its own: at a careless time step this code manufactures 67″ per century of spurious perihelion precession — more than the relativistic effect I wanted to measure. Without validation, a pretty animation proves nothing.
Solution
  • Real J2000 initial conditions (planets, dwarf planets, comets) in 3D, barycentric frame.
  • Four integrators compared head to head; the default is Yoshida 4, a fourth-order symplectic method, because its energy error stays bounded instead of drifting.
  • First post-Newtonian correction and solar J2; a black-hole module with an ISCO-based capture criterion; adaptive sub-stepping for close encounters.
  • A validation suite that tests conservation laws, convergence order and Kepler's third law on simulated orbits, run on GCC and Clang in CI.

KAIROS

Python · local-first

A modular, local-first personal AI assistant that talks, remembers, acts on my desktop — and proposes changes to its own code.

Problem
Cloud assistants know nothing about my context and send what they do learn to someone else's servers; local ones run privately but know nothing about me. I wanted one that does both, keeps working without internet, and can never execute something it invented.
Solution
  • A core plus specialised agents (voice, memory, reasoning, documents, automation, security, devices), each a bounded context behind one contract.
  • Hybrid language model: cloud reasoning with automatic fallback to a local model (Ollama) if the network fails before the first token. Embeddings never leave the machine.
  • Desktop control through a closed whitelist: the model chooses actions, it never writes commands.
  • Self-improvement pipeline: it writes a patch, tests it in a network-less sandbox, and leaves a proposal; a separate service merges it only after my approval and a green test run.
  • Encrypted phone access through Tailscale, with no port opened to the internet.

GetSympto

Shipped · paused

A web app that turns a symptom description into structured, understandable guidance — orientation, never diagnosis.

Problem
People describe symptoms in their own words, search across many sites, and end up with either too much information or no idea how urgently to act — often in a language that isn't theirs.
Solution
  • An interactive SVG body map plus free-text description; a language model constrained to return a structured report (possible causes, urgency level, next steps).
  • Positioned explicitly as an information tool, not a diagnostic system.
  • Anonymous by default; accounts only for saving reports and PDFs. Server-side validation, sanitisation and IP rate limiting.
  • Available in Spanish, English, Chinese and Russian.
