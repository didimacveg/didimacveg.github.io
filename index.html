TraceGuard

Continuous compliance auditing for physical products.

A push to a connected repository is checked against a machine-readable rule set — the EU Cyber Resilience Act, IEC 61508, a company's own risk assessment. A change that breaks a rule opens a GitHub or Jira ticket citing the line and the requirement, and every decision lands in an audit trail.

The model never has the last word. Its findings go through a verification layer that discards any finding whose rule doesn't exist in the document or whose quoted evidence doesn't appear literally in the diff. Severity comes from the customer's document, not from the model. A second component compiles a regulatory PDF into evaluable rules, and drops any rule that can't quote its source.

Kairos

A local-first AI assistant that writes patches to its own source code.

Seventeen agents behind an orchestrator, semantic memory over pgvector, wake-word voice, desktop control through a closed whitelist, Gmail and Calendar. The self-modification loop writes a patch, tests it in an isolated sandbox, reads the failures, fixes them — and waits for my approval.

Every architectural decision is written down as it was made, including the ones I got wrong and what they cost.

Gravity‑lab

An N-body simulator of the Solar System, checked against measurement rather than eyeballed.

Real J2000 initial conditions, four integrators, and a black-hole module that uses the Schwarzschild innermost stable circular orbit as its capture criterion.

With a first post-Newtonian correction it reproduces the anomalous precession of Mercury's perihelion — the discrepancy Le Verrier measured in 1859 and general relativity explained in 1915. The control case, with no perturbations and no relativity, returns exactly zero; without that, the rest would be numerical error.

About

I'm interested in the part of software that touches the physical world: robotics, control, safety. Code that only moves data around stops being interesting to me quickly.

Most of what I know is self-taught, which shows in both directions — I can build a multi-tenant system with a verification layer and a sandbox, and I still have gaps a formal education would close. I use AI heavily as a development tool and I'd rather say so than pretend otherwise. The architecture, the trade-offs and the decisions about what to build are mine, and I can defend each of them.
